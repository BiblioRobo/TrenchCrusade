This is an unofficial Trench Crusade repository for NewRecruit, forked from Fawkstrot11. Since they can no longer manage the data for TC, I decided to try my hand at it. This repo is NOT the official one for TC in NewRecruit, but I plan on applying to be listed as such once the data are in a better state.

My plan is to get all of the official content up to date first, including the new stuff from Carcass Front. Once that material is accurate, I'll move to the official third-party lists (Cadaver Corps, Great Hunger, etc).

Feel free to reach out if you'd like to collaborate! I'm very new to Github and editing data for NR, and appreciate any help offered.
